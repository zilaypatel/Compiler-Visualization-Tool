# Compiler-Visualization-Tool
An interactive web-based Compiler Visualization Tool that demonstrates lexical analysis, parsing, parse tree visualization, semantic analysis, and code generation.

A web-based tool to **visualize how a compiler works** step by step.  
This project demonstrates key phases of compilation such as:

- Lexical Analysis (Tokenization)
- Parsing (Recursive Descent Parser)
- Parse Tree Visualization (using D3.js)
- Semantic Analysis (error detection like division by zero)
- Intermediate Code Generation (Postfix / Reverse Polish Notation)

🚀 Built with **HTML, CSS, JavaScript, Bootstrap, and D3.js**.
